# 履歴書 自動作成システム（近畿高等学校統一用紙 その2）

Excel（またはGoogleスプレッドシート）に入力した内容が、そのまま履歴書のPDFに反映されます。
用紙は **近畿高等学校統一用紙 その2（令和7年度改定）** ＝ `templates/rirekisho_kinki_r7.pdf` を使い、
罫線や印字済みの文言はそのまま、入力した文字だけを上に重ねて書き込みます。

![出力イメージ](docs/sample.png)

## できること

| 入力する項目 | 自動で入るもの |
| --- | --- |
| 名前（ふりがな・氏名） | — |
| 生年月日 | **元号（昭和／平成／令和）の判定**、**満○歳の計算** |
| 現住所（郵便番号・住所・ふりがな） | 郵便番号を `123-4567` の形に整形 |
| 連絡先 | **空欄なら「同上」と印字** |
| 資格等（取得年月・名称） | 西暦で入力しても **和暦（令和6年6月）** で印字 |
| 校内外の諸活動 | 欄に合わせて自動折り返し・自動縮小 |
| 志望の動機／希望の職種／アピールポイント | 3項目を見出し付きで1つの欄にまとめて印字 |
| 職歴（年月・内容） | 元号の丸囲みを自動で付ける |
| 備考 | — |

長い文章は欄の幅で自動的に折り返し、入りきらないときは文字サイズを自動で小さくします。

## 使い方

### 1. 準備（最初の1回だけ）

```bash
pip install -r requirements.txt
```

Python 3.10以上が必要です。日本語フォントは自動で探します（Windowsの游ゴシック／メイリオ、
macOSのヒラギノ、LinuxのIPAゴシックなど）。見つからないと言われたら、環境変数で指定してください。

```bash
# Windows (コマンドプロンプト)
set RIREKISHO_FONT=C:\Windows\Fonts\meiryo.ttc
# macOS / Linux
export RIREKISHO_FONT='/System/Library/Fonts/ヒラギノ角ゴシック W3.ttc'
```

### 2. 入力シートを作る

```bash
python make_xlsx.py                 # 空の 入力シート.xlsx を作る
python make_xlsx.py --with-sample   # 記入例入りで作る
```

リポジトリにある `入力シート.xlsx`（空）や `samples/入力シート_記入例.xlsx` をそのまま使ってもかまいません。

### 3. 入力してPDFを作る

「入力」シートの**黄色いセル**に入力して保存したら、

```bash
python build_pdf.py                 # 入力シート.xlsx → 出力/履歴書.pdf
python build_pdf.py --png           # 確認用のPNGも一緒に出す
```

### 4. 入力しながら自動で反映させたいとき

```bash
python watch.py
```

を起動したままにしておくと、**Excelで上書き保存するたびにPDFが作り直されます**。
PDFビューア（Adobe Acrobat以外の、Edge・Preview・Chromeなど）で開いておけば、
再読み込みするだけで最新の状態を確認できます。Ctrl+Cで終了します。

## Googleスプレッドシートで入力する場合

1. `入力シート.xlsx` をGoogleドライブにアップロードし、スプレッドシートとして開いて入力する。
2. **ファイル → ダウンロード → Microsoft Excel (.xlsx)** または **カンマ区切り形式 (.csv)** で書き出す。
3. 書き出したファイルを指定して実行する。

```bash
python build_pdf.py ~/Downloads/入力シート.csv -o 出力/履歴書.pdf
```

> シートの **E列・F列（非表示）** に項目のキーが入っています。読み取りに使うので消さないでください。
> 行を増やすときは、キー（`license.9.ym` / `license.9.name` など）も一緒に入れてください。

## 入力の書き方

| 項目 | 書き方の例 |
| --- | --- |
| 生年月日 | `2008-05-12` / `2008/5/12` / `平成20年5月12日` / `H20.5.12` |
| 基準日（満○歳の計算日） | `2026-09-01`（用紙に印字された「令和8年9月1日現在」に合わせています） |
| 郵便番号 | `5980001` / `598-0001` / `〒598-0001` |
| 資格の取得年月 | `2024-06` / `令和6年6月` / `202406` |
| 複数行にしたい欄 | セル内で `Alt+Enter`（Macは `Option+Enter`）で改行 |

## 注意

- **写真**はPDFには合成しません。印刷した用紙の「写真をはる位置」に貼ってください。
- 用紙には最初から **「平成」に丸**、**「卒業見込」に丸**、在籍校名、「令和8年9月1日現在」が印字されています。
  生年月日が平成以外のときは自動でその元号にも丸を付けますが、印字済みの丸は消せないので、
  印刷後に手で消してください（実行時に注意メッセージが出ます）。
- 欄からあふれるほど長い文章は、自動縮小しても入りきらない分は印字されません。注意メッセージを確認してください。

## ファイル構成

```
├── make_xlsx.py            入力シート(.xlsx)を作る
├── build_pdf.py            入力シート → PDF
├── watch.py                入力シートを監視して自動でPDFを更新
├── templates/
│   └── rirekisho_kinki_r7.pdf   用紙（罫線と印字済みの文言）
├── rirekisho/
│   ├── layout.py           用紙の記入位置（座標）の定義
│   ├── model.py            和暦変換・満年齢・「同上」などの自動処理
│   ├── inputs.py           入力シートの定義・生成・読み取り
│   ├── render.py           PDFへの描画（折り返し・自動縮小・丸囲み）
│   └── fonts.py            日本語フォントの検出
├── samples/入力シート_記入例.xlsx
└── tests/                  pytest（python -m pytest）
```

用紙が改定されて記入位置がずれた場合は、`rirekisho/layout.py` の数値だけを直せば直せます。
座標は「印刷したときに見える向き」（A4横 842pt × 595pt、左上が原点）で書いてあります。
